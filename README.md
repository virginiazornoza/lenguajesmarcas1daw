## 🛠️ Novedades y Funcionalidades de la Aplicación

1. **Gestión de Visibilidad y Modo Docente**:
   * Interruptor de **"Acceso Docente"**.
   * Permite al profesor **bloquear o desbloquear** contenidos individualmente o por unidades completas para abrirlas a los alumnos al ritmo de las clases.
   * Los alumnos ven los bloques cerrados como protegidos hasta su explicación en el aula.
2. **Barra Lateral Adaptable**:
   * **Divisor arrastrable (Resizer)**: Arrastra el separador con el ratón para ajustar el ancho de la columna izquierda (entre 220px y 520px). Doble clic para restablecer al tamaño estándar (320px).
   * **Botón para ocultar/mostrar la barra lateral**: Permite maximizar al 100% el ancho disponible para el contenido teórico y el editor de código.
3. **Corrección de Renderizado de Etiquetas**:
   * Todas las etiquetas como `<titulo>`, `<modulo>`, `<alumno>` se muestran limpias y visibles mediante escape seguro de entidades HTML.
4. **Paleta Cromática Suave y Descansada**:
   * Combinación armónica de **Azul Índigo** corporativo con acentos en **Verde Azulado (Teal / Esmeralda)** y toques ámbar, ofreciendo un contraste suave y descansado para horas de trabajo en el aula de informática.
5. **Laboratorio Interactivo XML**:
   * Validador en tiempo real con diagnóstico pedagógico de fallos sintácticos en español y generador del árbol visual DOM.
   * Cuestionarios autocorregibles con explicaciones detalladas para cada opción.
